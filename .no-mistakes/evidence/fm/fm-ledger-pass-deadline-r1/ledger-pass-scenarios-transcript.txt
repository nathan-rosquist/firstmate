How these were driven
  Each block runs the real bin/fm-inactive-reconcile.sh (target a5f800b) over a
  real firstmate home built by the suite's own fixtures - a mate home bound to a
  parent home, real *.meta/*.status ledgers, real locks, real parent-channel
  appends - exactly as bin/fm-watch.sh and bin/fm-startup-network.sh invoke it.
  FM_INACTIVE_RECONCILE_BUDGET_SECS=30 (the documented maximum) is used because
  ONE ledger delivery costs ~16-19s of wall clock on this Cygwin/Windows host,
  well over the 10s default; S7 uses the suite's fake stepping clock so the
  deadline lands on a read count instead of on host speed.
